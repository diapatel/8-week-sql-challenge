## 🚀 Running the Queries

1. Set up the schema and seed data from the [official challenge page](https://8weeksqlchallenge.com/)
2. Run the relevant `solutions.sql` file in your PostgreSQL client
3. Each query is labeled with its question number and description

## 📌 Notes

- Where multiple valid approaches exist, I've gone with the most readable one
- Some questions have ties handled via `dense_rank()` to avoid dropping valid rows
- All date logic uses PostgreSQL's `INTERVAL` syntax
